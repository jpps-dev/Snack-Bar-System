# Snack Bar Cashier System

A simple snack bar cashier system developed as an academic project using HTML, CSS, and JavaScript.

The system simulates the main operations of a snack bar, allowing products to be registered, listed, sold, and tracked throughout the day.

## Features

- Register products
- Validate product names and prices
- Prevent duplicate products
- List registered products
- Perform sales
- Calculate sale subtotals
- Apply a 10% discount to sales above R$ 50.00
- Display the sale summary
- Track completed sales
- Calculate the total sales of the day

## Technologies

- HTML5
- CSS3
- JavaScript

## Concepts Used

This project was developed using basic programming concepts covered in class:

- Arrays
- Variables
- Conditional statements
- Repetition structures
- Functions
- Parameters and return values
- `prompt()`
- `confirm()`
- `alert()`

## Project Purpose

The project was created for an academic activity focused on applying basic programming concepts to a practical cashier system.
